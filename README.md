# CV Match — MVP

אפליקציה פשוטה להתאמת קורות חיים למשרה מתוך צילום מסך, לינק או תיאור חופשי.

## מה כבר עובד

- העלאת צילום מסך של מודעת דרושים וניתוח עם Vision.
- הדבקת לינק למשרה; השרת מנסה לקרוא את דף המשרה.
- תיאור משרה חופשי.
- יצירת קורות חיים בעברית, באנגלית או אוטומטית לפי שפת המשרה.
- מנגנון **לא ממציאים**: ה-AI מקבל פרופיל עובדות קבוע ומונחה לא להוסיף ניסיון שלא קיים.
- אם יש דרישה משמעותית שאין לה גיבוי בפרופיל, מוחזרות שאלות הבהרה למשתמש.
- תמונת פרופיל קבועה: `data/profile_photo.jpg`. היא משתנה רק דרך כפתור החלפה ואישור מפורש.
- פרופיל ניסיון קבוע וניתן לעריכה ב-`data/profile.json` או דרך המסך “הפרופיל שלי”.
- תצוגת CV של עמוד A4 וכפתור **שמור / הדפס PDF** דרך מנגנון ההדפסה של הדפדפן.
- הודעת WhatsApp/email קצרה מוכנה לשליחה.
- בלי API key האפליקציה עולה ב-Demo Mode, כדי שאפשר לבדוק את ה-UI.

## הפעלה

### Windows

```powershell
cd cv_tailor_mvp
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

פתח את `.env` והכנס מפתח API:

```text
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.6-terra
```

ואז:

```powershell
python app.py
```

פתח בדפדפן:

```text
http://127.0.0.1:5000
```

### macOS / Linux

```bash
cd cv_tailor_mvp
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

## עיקרון המוצר

הפרופיל הוא **מקור האמת**. מודעת המשרה לא משנה את העובדות; היא רק קובעת מה להבליט, מה לקצר ואיך לנסח. כשאין מספיק התאמה, המערכת שואלת לפני שהיא מוסיפה משהו חדש.

## לפני פריסה אמיתית

ל-MVP מקומי קובץ JSON מספיק. לגרסה בענן כדאי להעביר את הפרופיל, היסטוריית המשרות והתמונות למסד נתונים/Storage ולהוסיף Login. את `OPENAI_API_KEY` תמיד משאירים בצד השרת ולא בדפדפן.
